# Вопросы к PM

Вопросы, возникающие в ходе работы, и полученные ответы. Не додумывать неопределённость самостоятельно — фиксировать здесь и ждать ответа.

Формат записи:

```
## YYYY-MM-DD — Краткая формулировка вопроса

- Вопрос: ...
- Контекст: почему это важно / где возникла неопределённость
- Ответ PM: (заполняется после получения ответа)
- Статус: открыт / закрыт
```
